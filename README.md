## Getting Started

First, run the development server:

```bash
npm i
npm run dev
```
Setup a .env file with `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` to get the app up and running.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
